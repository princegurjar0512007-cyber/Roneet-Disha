# Roneet ❤️ Disha — Proposal Website

## Included
- `index.html` — complete website
- `style.css` — romantic responsive design
- `script.js` — music, hearts, scroll animations, YES/NO interaction
- `photos/` — your 4 uploaded couple photos
- `music/` — place your music file here

## Add the song
For the background music, put your legally obtained copy of the song in:
`music/dil-haareya.mp3`

The website is already coded to play that file when the visitor taps "Open Our Story".

## Run it
Double-click `index.html` to open it in a browser.

## Put it online for free
You can upload the folder to GitHub Pages or Netlify. Keep the folder structure unchanged so the photos and music load correctly.
